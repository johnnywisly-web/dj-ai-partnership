# DJ AI PARTNERSHIP LLC website package

Upload these files to the ROOT of the GitHub Pages repository:
- index.html
- dj-ai-partnership-llc-logo.png
- sitemap.xml
- robots.txt

After GitHub Pages publishes the site:
1. Open https://www.jdaipartnership.com/
2. In Google Search Console, inspect https://www.jdaipartnership.com/
3. Request indexing if needed.
4. In Search Console > Sitemaps, submit: sitemap.xml

The DNS verification you already completed does not need to be repeated.

Important: If your current index.html already contains a finished website, keep a backup before replacing it with this package.
