# DJ AI Partnership LLC — Site

Single-page site (`index.html`), self-contained (logo embedded, no external assets needed besides Google Fonts).

## Deploy on GitHub Pages

1. Push these files to your repository (root, or a `docs/` folder — your choice).
2. In the repo: **Settings → Pages**.
3. Under "Build and deployment", set **Source: Deploy from a branch**.
4. Pick your branch (e.g. `main`) and the folder (`/root` or `/docs`), then **Save**.
5. GitHub gives you a URL like `https://<username>.github.io/<repo>/` within a minute or two.
