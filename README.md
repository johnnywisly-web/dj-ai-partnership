# JDAI Partnership — Contractor Opportunity Website

Modern responsive landing page for an **individual contractor** AI-data/workflow opportunity.

## Included
- Modern responsive design
- Contractor-focused messaging (not an enterprise/company data partnership)
- Clear paid-opportunity positioning
- Mandatory eligibility/application flow
- Privacy and authorized-data safeguards
- Application form
- Mobile layout

## Important before production
1. Connect `applicationForm` in `script.js` to your real backend/form service.
2. Replace the generic compensation language with the actual approved contractor rate/terms.
3. Add your legal Privacy Policy, Terms, Contractor Agreement and data-processing language.
4. Use your verified company contact details.
5. Review all claims about data retention, ownership and confidentiality with your legal/compliance team before publishing.

## Run
Open `index.html` in a browser, or upload the folder to your web host.
